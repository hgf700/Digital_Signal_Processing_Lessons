# Digital Signal Processing – Laboratory Exercises

## Description
This repository contains a series of laboratory exercises focused on **Digital Signal Processing (DSP)** implemented in Python. The labs cover fundamental concepts as well as practical applications in signal analysis, filtering, stochastic processes, and real-world data such as images, audio, and biomedical signals.

---

## Laboratory List

### 1. Signal Synthesis using IDFT & DFT
- Signal synthesis using the **Inverse Discrete Fourier Transform (IDFT)**
- Understanding and implementation of the **Discrete Fourier Transform (DFT)**
- Reconstruction of signals from frequency-domain representation

---

### 2. FFT Windowing Techniques
- Analysis of window functions in FFT:
  - Rectangular
  - Hann
  - Hamming
  - Blackman
  - Kaiser
- Effects of windowing on spectral leakage and resolution

---

### 3. FIR, IIR and Adaptive Filtering
- Design and implementation of:
  - FIR filters
  - IIR filters
- Filtering signals in Python
- Introduction to adaptive filtering techniques

---

### 4. Sampling, Reconstruction and Quantization
- Sampling and reconstruction of signals
- Analysis of aliasing effects
- Delta encoding and decoding
- Quantization of signal samples
- Signal reconstruction after compression

---

### 5. Random Signal Analysis
- Analysis of stochastic signals
- Power spectral density estimation:
  - Periodogram method
  - Welch’s method
- Comparison of window types:
  - Boxcar
  - Hann
  - Hamming
  - Blackman

---

### 6. Stochastic Signal Models
- Generation and analysis of:
  - AR(2)
  - MA(2)
  - ARMA(2,2)
- Parameter estimation using Yule-Walker equations
- Introduction to ARIMA modeling
- Comparison between ARMA and ARIMA models

---

### 7. Image and Audio Signal Processing
- 2D Fourier Transform of grayscale images
- Visualization of magnitude spectrum
- Low-pass and high-pass filtering in frequency domain
- Image reconstruction after filtering
- Audio processing:
  - Spectrogram analysis
  - Time-domain vs frequency-domain comparison
  - Noise reduction using frequency-domain filtering

---

### 8. Biomedical Signal Processing Applications
- Analysis of biomedical signals:
  - ECG
  - EEG
  - EMG
- Feature extraction and signal interpretation
- DSP techniques in medical data analysis

---

### 9. Real-Time-like Signal Processing and Kalman Filtering
- Simulation of real-time ECG processing
- Kalman-Bucy filter introduction
- Scalar Kalman filter implementation
- Signal smoothing and state estimation

---

## Objective
The main goal of this laboratory series is to develop practical and theoretical understanding of:
- Digital signal processing fundamentals
- Frequency-domain analysis
- Digital filtering techniques
- Stochastic signal modeling
- Real-world DSP applications in audio, image, and biomedical domains
