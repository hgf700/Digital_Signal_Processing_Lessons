#   Spectral leakage (in DFT)
#A single frequency “spreads out” into many frequencies in the result. ex:
#one tone:  100 Hz (pure sound) But DFT shows: 95 Hz, 100 Hz, 105 Hz… (spread out)
#Why it happens: DFT assumes your signal: repeats perfectly in a loop

#   DTFT (Discrete-Time Fourier Transform) 
#is a way to see the frequencies in a digital signal (a sequence of samples).
#You have a signal made of numbers (like samples over time). DTFT tells you: “What frequencies are inside this signal?”
#DTFT: frequency output is continuous (smooth line) DFT: frequency output is discrete (separate points)

#   DTFT of a Discrete Exponential
#DTFT converts this growing/decaying sequence into its frequency representation.
#A discrete exponential is made of all frequencies mixed together DTFT shows how much of each frequency exists
#The result depends on a: if ∣a∣<1: signal decays → stable spectrum if ∣a∣>1: signal grows → spectrum is not stable

#   DTFT of a Truncated Discrete Signal
#A truncated discrete signal means: you take a signal and “cut it” to a finite length
#Example: Original signal: infinite sequence, Truncated signal: only first N samples
#When you truncate a signal, you are basically multiplying it by a window (like a box): original signal × window → truncated signal
#This “cutting” causes: spectral leakage because sharp cutting in time creates extra frequencies in frequency domain.

#   windowing:
#function that “cuts” or “selects” a part of a signal. 
#Instead of using an infinite signal, you: take only a section of it and multiply it by a window
#What it does: keeps the middle part of the signal reduces or removes the edges
#Why it’s used: Because cutting a signal suddenly causes distortion (spectral leakage). Windowing makes the cut smoother.

#Resolution - How well a method can separate two frequencies that are very close to each other.

#   window length
#it determines the balance between frequency and time resolution
#The window length in spectral analysis controls: how much time you look at at once
#Long window: better frequency resolution (more precise frequencies), worse time resolution (you don’t see quick changes)
#Short window: better time resolution (see changes quickly), worse frequency resolution (less precise frequencies)

#   window types
#When you cut a signal, you can: cut it hard (simple window) or cut it smoothly (better window)
#Rectangular window (hard cut) sharp time cut strong spectral leakage
#Smooth windows (Hann, Hamming, etc.) less leakage slightly blur frequency details

#A recursive system - The output depends on past outputs as well as inputs. (IIR filters)
#Recurrent - repeats or happens again and again.  (IIR filters)

#   Digital filters 
#modifies a digital signal to remove unwanted parts or enhance useful parts.
#A filter changes a signal (removes noise, selects frequencies...), window is mainly used to prepare a signal for
#analysis or filter design

#   FIR (Finite Impulse Response)
#uses: only current and past input values No feedback from output. 
#techique like window method, frequency sampling, or least-squares optimization
#Because the effect of an impulse (a single spike input) dies out after a finite number of steps. (zeroes at the end)
#Pros: Always stable, Easy to design, Can get perfect linear phase (important in audio/image processing)
#Cons: Needs more computation (more coefficients for sharp filters)

#   IIR (Infinite Impulse Response).
#uses: both past inputs AND past outputs (feedback)
#real coefficients Real-valued poles and zeros If the poles and zeros are real numbers, the coefficients will be real.
#Complex Conjugate Pairs If a pole or zero is complex, its conjugate must also be present.
#output depends: current input, past inputs, past outputs (feedback loop)
#Why “infinite” Because feedback makes the effect of one impulse last forever (theoretically).
#Pros: Very efficient (needs fewer coefficients), Achieves sharp filtering with less computation
#Cons: Can become unstable if not designed properly, Phase distortion (signal shape can get warped)

#   impulse signal
#the output of a system when you give it an impulse input
#FIR response non-zero only for a finite number of samples After that zero everywhere else
#FIR response even after input becomes zero output keeps depending on past outputs

#   Causal filters
#A causal filter is a filter that uses only the current and past input values to produce an output.
#In real-time systems, future data is not available yet, so systems use causal filters.

#   Bounded Input-Bounded Output(BIBO) / ograniczony (zakres) input output
#Input stays within a fixed limit → Output also stays within a fixed limit.
#The output does not grow to infinity when the input is finite.
#when infinite  stability depends on the placement of the poles if lies outside filet is unstable

#   Adaptive filtering
# adjust their parameters automatically to changes in the input signal. This makes them suitable
#for applications where the signal or noise characteristics are not constant over time.
#Noise reduction → removes unwanted noise (backgound noise, electrical interference, etc.).
#Echo cancellation → removes echoes caused by signal reflections or acoustic feedback 
#(during phone calls).
#Speech enhancement → improves speech quality by reducing background noise.

#   Direct Form II
#Feedforward (Non-recursive) - Uses the current and past inputs.
#Feedback (Recursive) - Uses the past outputs.
#Direct Form I uses 4 delay elements (memory units). Direct Form II uses only 2 delay elements by sharing them between
#the feedforward and feedback parts. So Direct Form II: Needs less memory. Is more efficient.

#   Zero-Phase Filters
#A zero-phase filter is a filter that does not shift the signal in time.
#Phase is about time shifting of a signal. Normal filters often delay or shift the signal.
#A zero-phase filter removes this delay. No time shift, Output is aligned with input
#achieved Filtering the signal forward Then filtering it backward

#   Causal Linear-Phase Filters 
#A linear-phase filter changes the signal without distorting its shape, because it delays all frequency 
#components equally.
#linear phase All frequencies are delayed by the same amount of time So the waveform shape is preserved

#   Power Spectrum Estimation
#Estimating the Power Spectral Density (PSD) of a signal from measured data. Find which frequencies are present
#Determine how much power each frequency contains
#Non-parametric - not assume a model (AR, MA, or ARMA) for the signal. we calculate the spectrum directly from the data.
#Periodogram - Take the signal samples. Compute the Fourier Transform (usually FFT). Square the magnitude.

#   Bartlett Method 
#improved version of the periodogram used to estimate the Power Spectral Density (PSD).
#A single periodogram can be: Noisy and unstable
#Instead of using the entire signal at once: Split the signal into several equal segments. Compute a periodogram for 
#each segment. Average all the periodograms.

#   Welch Method
#improvement over the Bartlett Method for estimating the Power Spectral Density (PSD).
#Split the signal into segments Allow segments to overlap (often 50%) Apply a window (Hamming, Hann, etc.) to each 
#segment Compute a periodogram for each segment Average all periodograms

#   Yule-Walker Method
#parametric method for estimating the Power Spectral Density (PSD).
#Instead of calculating the spectrum directly from the signal We assume the signal can be modeled by an AR model.
#Then we estimate the AR coefficients and use them to obtain the PSD.

#   Burg’s Method
#parametric to estimate the Power Spectral Density (PSD) by fitting an AR model to a signal.
#Instead directly computing the spectrum, build AR model that best represents the signal, then use it to find the PSD.
#estimates AR coefficients by Minimizing both forward and backward prediction errors Ensuring the AR model is stable

#   Resolution for methods (separate two frequencies that are very close to each other.)
#Classical Periodogram Good resolution if the signal is long If few samples → poor resolution
#Bartlett Method Each segment is shorter → worse resolution But smoother (less noise in estimate)
#Welch Method Better than Bartlett Still lower than full periodogram More stable and smoother result
#Parametric Methods (AR) Very high resolution Can detect very close frequencies even with few samples Depends strongly
#on correct model order

#   Variance for methods (stable or consistent the PSD estimate is when you repeat the experiment with different signals.
#High variance  PSD looks different each time (unstable) Low variance → PSD looks similar each time (stable))
#Classical Periodogram - Uses one signal only No averaging High variance PSD looks noisy and unstable
#Bartlett Method - Split signal into parts Average results Lower variance than periodogram Smoother PSD
#Welch Method - Like Bartlett overlapping segments windowing Even lower variance Very smooth and stable PSD
#Parametric Methods (AR) - Assume a model for the signal Very low variance if model is correct
#Very stable and sharp spectrum But: If model is wrong → variance increases a lot (bad estimate)

#When to Use Non-Parametric Methods: Large datasets where computational efficiency is important. No prior knowledge
#of the signal model Applications where smoothing (e.g., Welch method) is acceptable.

#When to Use Parametric Methods: Short datasets where higher resolution is required. The underlying signal follows
# a predictable model (e.g., AR or ARMA process). Applications requiring sharp spectral peaks (e.g., speech or 
#vibration analysis).

#Challenges in Non-Parametric - Variance of the Estimate: Single-periodogram estimates have high variance.
#Leakage: Signal discontinuities introduce spectral leakage. Resolution: Frequency resolution depends on the total 
#observation time

#Challenges in Parametric - Order Selection: Overestimating order leads to overfitting. Model Mismatch: Assumes a
#specific process (e.g., AR or ARMA) for the signal Sensitivity to Noise: can distort the estimated autocorrelation function.
